# Sales Analytics (advanced pandas)

An end-to-end e-commerce analytics project: messy data in, cleaned dataset, business metrics, charts and a Markdown report out. Built with pandas, NumPy and matplotlib only.

## Run it

```bash
pip install -r requirements.txt
python -m streamlit run app.py   # interactive dashboard (opens in your browser)
python main.py all               # command line: generate data, clean, analyse, chart, write report
python main.py run               # re-run analysis on existing data/raw_sales.csv
python -m pytest                 # invariant tests
```

CLI options: `--customers 5000`, `--seed 1`, `--horizon 6` (forecast months), `--z-threshold 8`, `--data path.csv`, `--out folder`.
The CLI writes to `output/`: `report.md`, `charts/*.png`, `tables/*.csv`, `clean_sales.csv`.

## Dashboard (`app.py`)

A Streamlit web app on top of the same analytics code:

- **Sidebar:** use the sample data or upload your own CSV, filter by date, region, category and channel, and set forecast months and anomaly sensitivity.
- **KPI cards** that update with every filter.
- **Tabs:** Overview (trend + forecast), Products & regions, Customers (Pareto + RFM segments), Retention (cohort heatmap), Anomalies (zoomable), Bought together, and Data (cleaning log + downloads).
- Charts have hover tooltips, and each table has a CSV download.

## What it does

| Module | Advanced pandas techniques |
|---|---|
| `data_generator.py` | Vectorised NumPy simulation; customer lifetimes, seasonality, planted flash sales; injected dirt (duplicates, mixed date formats, `₹1,299.00` prices, casing, NaNs, invalid quantities) |
| `cleaning.py` | `DataFrame.pipe` pipeline of pure steps, a `CleaningReport` audit log, multi-format date parsing, regex price parsing, dtype optimisation (`category`, `int16`, `float32`) cutting memory ~40% |
| `analytics.py` | Named aggregation, `pivot_table`, `groupby().transform`, `resample`, rolling median/MAD, `qcut` scoring, `np.select`, `crosstab` + matrix product |
| `charts.py` | Six matplotlib charts, no dual axes, sequential single-hue heatmaps |
| `report.py` | Markdown report with formatted tables and an embedded data-quality log |

## Analyses

1. **KPIs**: revenue, AOV, repeat-customer rate, return and cancellation rates, discount cost.
2. **Monthly trend**: MoM, YoY and 3-month rolling average.
3. **Category x region pivot** and top products, channel mix.
4. **Pareto concentration**: share of customers and products driving 80% of revenue.
5. **Cohort retention**: first-order cohorts, months-since-first-order matrix with unobservable cells masked.
6. **RFM segmentation**: quintile scores to Champions, Loyal, At Risk and others.
7. **Anomaly detection**: robust z-score (median / MAD, trailing 28-day baseline, shifted so a day never judges itself). It finds the planted flash-sale days.
8. **Forecast**: trend x seasonal index; linear vs log trend picked automatically on a 3-month hold-out (MAPE reported).
9. **Market basket**: product pairs ranked by lift.

## Using your own data

Replace `data/raw_sales.csv` with a CSV that has these columns: `line_id, order_id, order_date, customer_id, customer_name, product_id, product_name, category, region, channel, quantity, unit_price, discount_pct, payment_method, order_status` (status values: Delivered / Returned / Cancelled), then run `python main.py run`.
